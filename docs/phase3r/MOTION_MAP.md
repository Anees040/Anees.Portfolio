# Complete motion map

This is a proposed implementation contract, **not a list of effects already shipped**. Absolute normalized scroll progress is authoritative for narrative scenes; independent clocks belong only to finite pixel simulation and explicit game play. Durations read the existing CSS authority: hero/media 600ms, stagger 80ms, press 150ms, release 100ms; ease `cubic-bezier(0.23, 1, 0.32, 1)`. Scrubbed positions use linear progress, not time easing or a spring lag. Mobile means actual fit/input capability, not a UA string.

## Technique and ownership map

| Technique | Scenes / limits |
| --- | --- |
| Scroll scrub | Work, Thread; small secondary About/Engineering/Contact transforms use the same scroll infrastructure |
| Pin | Work and Thread only; avoid adjacent pins; fit gate includes root text size, header, caption/nav and tallest content |
| Sliding background | Hero seam, four Work planes, Thread station backplates, Contact seam; no global overlay covering links |
| Sprites | Optional studio parts and required game atlas **after approval**; no fake rig from contact sheet |
| Canvas | Pixel portrait and hero-local background; isolated game; diagrams/reading are SVG/DOM, not all canvas |
| Image reveal | Studio, project screens, case galleries; stable semantic image is default |
| Text animation | Hero line entrance, Studio background traverse, Work sideways title swap, Contact short line; no screen-reader letter soup |
| Hover | Fine-pointer studio depth, localized portrait field and restrained actionable-link feedback; never reveals essential content |
| Native controls | Navigation, inspection views, notes, workbook, lab, chapter links, game, email copy; never decorative substitutes |

## Lifecycle and interruption acceptance

- At live reduced-motion change, revert pins/transforms and stop loops immediately; restore the corresponding real chapter's position/focus, not the page top. No in-flight tween may leave content hidden.
- Offscreen or hidden pauses game and pixel work; settled hero holds a complete image without perpetual rAF. Returning restores state; it does not replay the entire page.
- Worker failure restores a **fresh** canvas or static image; a transferred canvas cannot simply be reused as a main-thread context.
- Direct hashes, keyboard focus, reverse scroll and resize all derive from the same chapter state. Avoid stale active labels or focusable content hidden in offscreen panels.
- The board's three-state storyboard slider is deliberately **not** proof of any of these runtime behaviors. Implementation acceptance needs slow-scroll/reverse-scroll recordings, not only stills or assertions.
