# Skills demonstrated through projects

The portfolio describes actual project use and current exploration, not proficiency levels, years of experience or professional certification.

## Mobile and languages

Flutter and Dart appear in FitPilot, Sukoon and EduVerse. FitPilot uses Riverpod for application state. Sukoon uses Kotlin for native Android scheduling and interruption-state behavior. MethodChannel connects Sukoon's Flutter configuration to its Android responsibilities.

## Data and service connections

FitPilot uses SQLite for local records and Supabase for remote synchronization. EduVerse uses Firebase Authentication and Firebase Realtime Database, not Firestore. Sukoon connects to native Android APIs through MethodChannel. GitHub provides public source evidence for FitPilot, Sukoon and EduVerse.

## AI exploration and limits

FitPilot and EduVerse contain AI-related capture, coaching or study-tool integrations. The portfolio treats these as applied AI learning and exploration, with correction and output limitations. An integration does not establish model quality, production reliability or training a foundation model. No verified SportLynk technology stack is published. Do not infer other technologies or proficiency from interests alone.
