# Portfolio experiences

The portfolio presents About, Selected Work, Engineering, Follow the Thread, Build Circuit, Concurrency Lab, Evidence, Certificates and Contact. Four case studies cover SportLynk, FitPilot, Sukoon and EduVerse. These are public explanations and evidence, not production usage metrics.

## Build Circuit

Build Circuit is an original local educational interaction within the portfolio. It is not a commercial project or a model of SportLynk's deployed infrastructure. It joins the portfolio's engineering exploration; do not infer users, revenue or a separate product launch.

## Concurrency Lab and evidence

Concurrency Lab is a simplified local educational demonstration of concurrent booking requests and shared state. A static reading alternative is available. It is separate from SportLynk's private backend. Evidence links to genuine project repositories, source observations and approved project roles. The Certificates section has no verified records.
